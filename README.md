# De regreso al Indio — plano del predio

Plano interactivo del Parque Boronat para el domingo 18/10.

- Abrí la página, activá **Mover cosas** y arrastrá los sectores. Tocá un sector para cargar notas, responsable y emprendedores.
- Los cambios se guardan en el navegador de cada uno. No hay servidor.
- Para que todos vean una versión: **Descargar datos** baja un `datos.js`; reemplazá el de este repo con ese archivo y GitHub Pages lo publica.
- **Plano original** descarta los cambios del navegador y vuelve a lo que dice `datos.js`.

Archivos: `index.html` (la página), `datos.js` (el plano y los emprendedores), `local-db.js` (guardado en el navegador), `mapa.svg` (mapa base, calles y caminos de OpenStreetMap).
